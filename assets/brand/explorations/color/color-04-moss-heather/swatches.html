22 px: idle / working / attention+badge | mono 45% / 75% / 100%+badge16 px: the same six
Each cell: dL* / contrast ratio between the two colours; the tertiary row adds the hue gap. Highlighted cells are the tray pairs, which must be >= 12 L* apart: the three tray states are one family at three lightness steps (dim stone, the accent, the accent lit up), so a monochrome tray and a 16-colour terminal still tell them apart; attention also carries the badge dot. Success / error / info are text semantics separated by hue; where a cell is below 12 they are not distinguishable by lightness alone, and the UI never relies on that (they always come with a word). tertiary (subagent markers, graph series) sits beside state dots, so it must be >= 12 L* or >= 60° from every state. Monochrome tray tints: idle 45% = L* 49, working 75% = L* 72, attention 100% = L* 91. The bars under the table are the six tray icons at 22 and 16 px; tray-sizes.png beside this sheet is the same set rendered with tools/render.mjs and upscaled with hard pixels.
