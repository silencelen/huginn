# User guide

- [Sessions](sessions.md): the core of Huginn. Attach, mirror, reconnect, rename and end
  persistent Claude Code sessions.
- [The console](console.md): `huginn` in a terminal opens a full-screen view of everything.
- [The apps](apps.md): the desktop app (Windows, Linux) and the Android app.
- [Chats](chats.md): one-off questions and tasks, read-only (ask) or with tools (act).
- [Notifications](notifications.md): what notifies, where it shows up, and the optional alert
  relay.
- [Devices](devices.md): let Huginn run work on your other computers, within limits you set on
  each.
- [Projects](projects.md): a group of sessions led by one, for larger pieces of work.
- [Rounds](rounds.md): unattended work on the server on a schedule, with a report.
- [Usage limits](usage-limits.md): how Huginn watches your plan's limits and keeps work moving.
- [Hosted apps](hosted-apps.md): the web pages your server serves, listed and checked.
- [Claude Code skills](skills.md): what Claude Code learns about Huginn on your computers and your
  server, and `huginn doctor`.
- [Local AI](local-ai.md) (experimental): local models served from a computer with a GPU.
