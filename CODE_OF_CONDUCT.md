# Code of Conduct

## Our pledge

We want Huginn to be a welcoming, harassment-free project for everyone, regardless of experience level, background, or identity.

## Standards

**Encouraged:** kindness, constructive feedback, respect for differing viewpoints, gracefully accepting criticism, focusing on what's best for the project.

**Not tolerated:** harassment, insults, personal or political attacks, publishing others' private information, or any conduct that would be inappropriate in a professional setting.

## Scope

This applies in all project spaces — issues, pull requests, discussions — and when representing the project in public.

## Enforcement

Maintainers may remove, edit, or reject contributions and comments that violate this code, and may temporarily or permanently ban any contributor for behavior they deem inappropriate. Report concerns via a GitHub issue (or the private channel noted in [`SECURITY.md`](SECURITY.md) if sensitive).
